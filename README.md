## 📌 Project Overview

**InvenGuard** is a web-based inventory stock management system developed for Strength Electrical (M) Sdn Bhd. This system aims to enhance inventory control processes by improving efficiency, user accessibility, and data security across different departments (admin, office staff, and site staff).

---

## 💻 Features

- **Admin Panel**: Approve requests, manage users, view system logs.
- **Office Staff Panel**: Fulfill tool requests, update stock, and manage item data.
- **Site Staff Panel**: Request and checkout tools, view request status and history.
- **Real-time stock tracking** with low stock indicators.
- **Role-based access control** and security features.
